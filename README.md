# c# WEEKS PRACTISE
C# PROGRAMING LANGUAGE
Key Topics in Chapter 2
C# Program Structure

Console & GUI Apps: Overview of event-driven programming (GUI) versus sequential execution (Console).

Controls & Names: Assigning meaningful Name properties to controls (e.g., btnCalculate, lblResult, txtInput).

Variables and Data Types

Declaration: Specifying type and identifier (e.g., int age;, double price;).

Common Types:

int for whole numbers

double and decimal for floating-point values (use decimal for currency calculations)

string for text and char for single characters

bool for true/false values

Input, Output, and Parsing

Reading Input: Retrieving text from TextBox.Text or Console.ReadLine().

Type Conversion (Parsing): Converting strings into numbers using methods like int.Parse(), double.Parse(), or decimal.Parse().

Displaying Output: Converting numbers back to text using .ToString() or string interpolation (e.g., $"{amount:C}" for currency formatting).

Arithmetic Operations & Expressions

Basic operators: addition (+), subtraction (-), multiplication (*), division (/), and modulus (%).

Operator precedence and parenthetical grouping.

Constants and Field Variables

const Keyword: Declaring fixed values that cannot be altered during runtime (e.g., const double TAX_RATE = 0.07;).

Scope & Lifetime: Difference between local variables (inside methods) and class fields.
